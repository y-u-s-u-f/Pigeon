Pigeon GitHub

Email and calendar,
at the speed of your keyboard.

A fast Gmail and Google Calendar app for macOS. Built in Rust, drawn on the GPU, no web views.

Try It View on GitHub

What it does

Keyboard first

Every action has a shortcut, and ⌘ K finds any command. Gmail keys like J K and E work too.

Native and light

Written in Rust with GPUI, the UI framework behind the Zed editor. Opens fast and stays small.

Mail and calendar together

Week, month and agenda views, quick add, repeating events, reminders and Google Meet links.

Your mail stays on your Mac

Pigeon talks to Google directly and keeps a local copy. No server in between. Changes made offline are sent when you're back online.

Lives in the menu bar

A menu bar panel, notifications and a Dock badge, so new mail reaches you with the window closed.

Works with AI agents

An optional built-in MCP server lets the AI tools you choose read and act on your mail and calendar.

Try it

Pigeon is in early development and there's no download yet. To try it, build it from source on a Mac with Rust installed. Demo mode runs on sample data, so you don't need to sign in.

git clone https://github.com/y-u-s-u-f/Pigeon
cd Pigeon
PIGEON_DEMO=1 scripts/run.sh

Signing in to your own Google account needs a Google Cloud OAuth client for now.
