# Pigeon

Rust + GPUI macOS email and calendar app. Front end only, on placeholder data for now; the backend comes later (track needs in `docs/BACKEND_REQUIREMENTS.md`).

## Workflow

1. One or more `implementer` agents make the changes quickly. If there is a lot, split the work by non-overlapping files.
2. A separate `tester` agent tests the result with Cua Driver.
3. A fresh `implementer` fixes what the tester reports.
4. Re-test as needed.

Don't have one agent implement, test and fix in a loop.

Placeholder data (`assets/*.json`) is generated by a Claude Haiku 5.5 agent (`anthropic/claude-haiku-5-5`).

## Running and testing

- Run with `cargo run --release`.
- GUI testing uses Cua Driver only, scoped to the Pigeon process's pid and window. Never send input to other apps. Never change system appearance or wallpaper.
